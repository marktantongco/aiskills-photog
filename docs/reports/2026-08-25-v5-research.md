## 2. LLM provider decision

**Selected: Google AI (Gemini) API** — `gemini-2.0-flash` via `generativelanguage.googleapis.com/v1beta`.
Why: generous free tier, CORS-enabled browser-side calls (no backend needed for this static GitHub Pages site), single-key setup.
Security model: key is entered by the visitor at runtime, stored only in their `localStorage` (`aisf.gemini.key`), never committed to the repo.
Fallback: heuristic scorer runs fully offline; every failure path (no key, HTTP error, empty reply) degrades gracefully with a clear message.
